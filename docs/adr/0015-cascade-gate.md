# ADR-0015: Ворота каскада и реальная доля ML-трафика

- **Дата:** 2026-09-29
- **Статус:** Принято

- Ворота = порог оценки стадии 1 (или сильный сигнал), подбираются по полноте с пределом доли трафика в ML. На синтетике (много трудных легитимных актёров) в ML уходит ~42% трафика, из них обычные абоненты 12%; в реальной сети доля будет ниже. Не подгоняли ворота под красивую цифру.
- Известное слабое место: корпоративные мультисим (много номеров одного абонента) — review 13%, одна блокировка из 177 тыс.; в эксплуатации закрывается allowlist корпоративных номеров.
