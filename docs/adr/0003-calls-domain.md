# ADR-0003: Транзакционный домен заменяется доменом звонков

- **Дата:** 2026-09-28
- **Статус:** Принято

- Решение: `/v1/decisions` (транзакции) заменяем на `/v1/calls/score`; инфраструктурный слой (middleware, auth, fail-mode, идемпотентность, store, Docker/CI) сохраняем; velocity → переиспользуем как основу window-store.
- Обоснование: кейс — звонки; заготовка сама называет транзакционную логику демонстрационной (codebase/NOTES.md).
- Последствия: OpenAPI и тесты переписываются; старый эндпоинт удаляется в отдельном шаге после того, как новый готов (без промежуточной поломки CI).
