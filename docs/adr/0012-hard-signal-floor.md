# ADR-0012: Жёсткий пол вердикта для подмены номера

- **Дата:** 2026-09-29
- **Статус:** Принято

- Решение: сигналы `spoof` (российский номер при иностранном входе) и `unallocated` (номер вне распределённых диапазонов) — прямое свидетельство подмены, а не вероятность. Вердикт не ниже `review` независимо от модели (`decide.HardSignals`); block из-за пола сам по себе не наступает; экстренные службы всегда allow. Ответ содержит `rule_floor` и первую причину — правило своими словами.
- Обоснование: на холодном вызове (первый вызов номера без истории) обученная модель не уверена: легитимные SIP-транки тоже «холодные», а признаки истории нулевые. Без пола пример из ТЗ получал allow (score 0,0002-0,003). Пол даёт предсказуемость, которую можно защитить перед регулятором.
- Ограничения: легитимные SIP-транки и облачные АТС с российским номером через зарубежного оператора получают review (не block). Бюджет FPR при подборе порога ML уменьшается на число легитимных вызовов, отмеченных полом.
- Контракт с Python: биты сигналов (spoof=1, unallocated=2) зафиксированы тестом `TestSignalBitsAreStableContract`; Python — `HARD_SIGNALS_MASK` в `training/evaluate.py`.
