# ADR-0013: Роумер в синтетике входит как домашний абонент

- **Дата:** 2026-09-29
- **Статус:** Принято

- Исправление ошибки моделирования: сначала роумеры приходили с российским номером при иностранном входе, то есть паттерн из ТЗ был помечен легитимным, и модель этому научилась. Абонент в роуминге входит в сеть через собственного оператора, не через международный транзит. Иностранный вход с российским номером оставлен у 10% таких абонентов как легитимные SIP-транки.
