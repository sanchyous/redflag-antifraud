# ADR-0014: ML-сервис — необязательный профиль compose

- **Дата:** 2026-09-29
- **Статус:** Принято

- Решение: сервис `ml` включается `COMPOSE_PROFILES=ml` в .env на сервере. Без него ядро работает на линейной стадии.
- Обоснование: сборка Python-образа требует PyPI, а с VM (и с ноутбука без VPN) недоступны PyPI, Docker Hub и proxy.golang.org. Деплой ядра не должен зависеть от Python-образа.
- Последствия: доставка образов на VM — через `docker save | ssh docker load` (см. WORKLOG).
