# ADR-0002: Аддитивная логит-модель + правила

- **Дата:** 2026-09-28
- **Статус:** Принято

- Решение: скоринг = логистическая регрессия на монотонно преобразованных признаках + hard-правила.
- Обоснование: объяснимость по построению (вклад = w·(x−x̄)), детерминизм, быстрый инференс (мкс), легко защитить перед регулятором.
- Ограничения: не ловит сложные взаимодействия признаков — частично компенсируем правилами и графовыми признаками.
