# ADR-0001: Ядро на Go, без Python

- **Дата:** 2026-09-28
- **Статус:** Частично заменено ADR-0010 (ML вынесен в Python-сервис; ядро остаётся на Go)

- Решение: весь код (справочник, признаки, граф, скоринг, обучение, оценка) на Go.
- Обоснование: указание владельца; единый бинарь, простой деплой в существующий CI/CD; меньше межсервисных точек отказа.
- Ограничения: нет готового CatBoost/NetworkX; граф и обучение — своя небольшая реализация.
- Последствия: логистическая модель с точными вкладами вместо GBDT на первом этапе; GBDT — опция (T8.1).
