# ADR-0018: Офлайн-графовый анализ (NetworkX) в обучении — рядом с онлайн-эвристикой Go

- **Дата:** 2026-10-06
- **Статус:** Принято

- Решение: признак «веер» в проде по-прежнему считает Go на скользящем окне (`internal/detection/graph/fan.go`,
  ADR-0001) — это горячий путь, менять его на Python/NetworkX означало бы обменять микросекунды на миллисекунды
  без выигрыша в качестве. NetworkX подключён в `services/ml/training/graphfeat.py` как офлайн-инструмент
  обучения: строит граф вызовов набора целиком (`caller → callee`), считает его структуру (компоненты, степени,
  сообщества — greedy modularity) и независимо, графовыми методами, находит кандидатов в «веер» — без
  ограничения на окно, которое есть у боевой эвристики.
- Обоснование: кейс прямо называет NetworkX в рекомендованном стеке для графовых признаков. Внедрять его в
  горячий путь не нужно и вредно (сеть не выдержит миллисекундные графовые алгоритмы на каждый вызов), но как
  инструмент обучения он даёт то, что online-эвристика Go не может: анализ на полном графе без ограничения
  окна. Результат — не новый признак модели (чтобы не сломать контракт `features.Names` между Go и ML-сервисом,
  см. ADR-0010), а раздел отчёта обучения (`report.json`/`report.md`, раздел «Графовый анализ связей») со
  сверкой «сколько веера нашёл Go, сколько — NetworkX, где расхождение» — честная граница online-эвристики,
  а не скрытая.
- Для этого экспорт датасета (`cmd/export`, `internal/lab/mltrain`) дополнен колонкой `callee` (была только
  `caller`): без пары звонков граф не построить. Колонка не маскируется (обучающий набор — синтетика или
  выгрузка организаторов, не прод-трафик) и наружу (API, панель) не публикуется.
- Ограничения: попарное сравнение списков адресатов внутри «аномальной» когорты — O(n²); при наборе больше
  1500 кандидатов (`max_candidates`) берутся top-N по числу вызовов, это отражается в отчёте полем `capped`,
  а не скрывается. Сообщества (modularity) — необязательная часть сводки: при сбое (большой разреженный граф)
  отчёт не падает, просто `communities: null`.
