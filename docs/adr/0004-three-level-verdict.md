# ADR-0004: Решение трёхуровневое, автоблок — отдельная политика

- **Дата:** 2026-09-28
- **Статус:** Принято

- Решение: allow/review/block; block требует высокий score + ≥K независимых сильных сигналов + не protected.
- Обоснование: требование ТЗ об отдельной цене ошибки автоблокировки; вопрос про скорую.
- Последствия: защитный слой — жёсткий инвариант, покрыт обязательным тестом.
