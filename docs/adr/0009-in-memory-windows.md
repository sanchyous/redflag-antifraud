# ADR-0009: Окна по номерам в памяти процесса, Redis убран

- **Дата:** 2026-09-28
- **Статус:** Принято

- Решение: состояние окон — 256 шардов с мьютексами в памяти Go-процесса; окно считается по времени события; Redis из compose и go.mod удалён.
- Обоснование: поход в Redis ~100 мкс на вызов против ~1 мкс шарда; ядро под большой поток. Одни и те же признаки в онлайне и при обучении (детерминированное проигрывание).
- Ограничения: состояние теряется при рестарте (окно прогревается); горизонтальное масштабирование — маршрутизацией по хэшу номера на инстанс; память ограничена (24 байта × 512 событий на номер, вытеснение).
- Последствия: без Redis/Postgres ядро работает; журнал в Postgres — асинхронный и некритичный.
