# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Не выпущено]

### Изменено
- Горячий путь: специализированный кодировщик ответа, пулы буферов, проверка уровня логов до сборки записи — обработчик ускорен на 32%
  (1,85 → 1,25 мкс, аллокаций 43 → 31), сквозная пропускная способность 102 → 126 тыс. запросов/с. См. [docs/performance.md](docs/performance.md).
- Ядро подхватывает ML-сервис в течение 5 секунд после его запуска (раньше — до минуты); в JSON-логах версия сборки — поле `build`, без дубля ключа.

### Добавлено
- Нагрузочный тест `cmd/loadtest` (закрытая и открытая модель), отладочный `pprof` (`PPROF_ADDR`, только loopback).
- Панель мониторинга `/ui/` в стиле Zabbix, встроенная в бинарь ядра: показатели, графики, проблемы с разбором факторов, компоненты,
  граф вееров, модель, интерактивная проверка вызова.
- Эндпоинты для панели: `/v1/status`, `/v1/stats`, `/v1/events`, `/v1/model`, `/v1/graph/fans`.
- Телеметрия в памяти (`internal/platform/telemetry`): ряды по секундам и минутам с перцентилями задержки, без блокировок на горячем пути.
- Структурированное логирование (`internal/platform/logx`): форматы json и pretty, `request_id`, компоненты, ограничение частоты горячих событий;
  события состояния (breaker ML, версии моделей, веера); то же в Python-сервисе.

### Изменено
- Структура репозитория: пакеты `internal/` разложены по слоям (`telecom`, `detection`, `decision`, `platform`, `lab`), Python-сервис
  перенесён в `services/ml`, добавлены `docs/`, `Makefile`, линтеры (`staticcheck`, `ruff`) в CI.

## [1.0.0] — 2026-09-29

### Добавлено
- Скоринг вызовов по метаданным: обогащение номеров офлайн-справочником Россвязи, окна по номерам, граф связей («веер»),
  сигналы подмены номера, защитный слой (экстренные службы всегда `allow`).
- Каскад: линейная стадия 1 (Go) и ML-стадия 2 (Python, CatBoost + SHAP) с откатом при сбое.
- Объяснимые решения: факторы с вкладом, жёсткий пол `review` для подмены номера.
- HTTP API, журнал решений в Postgres, метрики Prometheus, `scripts/demo.py`, загрузка внешних выгрузок (`ingest`), оффлайн-прогон файла (`scorefile`).
- Обучение обеих стадий (`scripts/retrain.sh`) на синтетических данных с «трудными» легитимными абонентами.
